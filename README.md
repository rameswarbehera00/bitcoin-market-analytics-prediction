# Bitcoin Historical Market Intelligence & Price Trend Prediction

An end-to-end Data Analytics and Predictive Machine Learning project submitted for the AICTE | IBM SkillsBuild Internship.

## Project Overview
This project converts granular Bitcoin trade data into daily intervals to construct a 5-tier Business Intelligence decision system: tracking market KPIs, identifying volume/momentum drivers, training a predictive Random Forest Classifier, and providing actionable risk mitigation strategies.

## Dataset
- **Name:** [Bitcoin Historical Data](https://www.kaggle.com/datasets/mczielinski/bitcoin-historical-data)
- **Source:** Kaggle (Bitstamp BTC/USD Exchange Data)
- **Granularity:** 1-minute intervals resampled to daily OHLCV

## Technologies Used
- Python 3.x
- Jupyter Notebook (`.ipynb`)
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
